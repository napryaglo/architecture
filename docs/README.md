# Documentation

## Diagram subsystem

- [Diagram API Guide](diagram-api-guide.md) — developer reference for the
  diagram framework: `DiagramDocument`, the `Diagram` control, `Figure` /
  `Group`, shapes, text (`ShapeText`, rich content, fields, auto-fit),
  `TextShape` / `Callout`, connectors (endpoints, ports, routing, caps),
  mutation wiring, persistence, and the enum / free-function indexes.
- [Diagram User Manual](diagram-user-manual.md) — end-user guide to the
  Diagrammer: adding, selecting, moving, aligning, grouping, and combining
  shapes; drawing and editing connectors; text and labels; formatting;
  save / load; and a keyboard / mouse reference.
